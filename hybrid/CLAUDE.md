# CLAUDE.md

This file provides guidance when working with code in this repository.

## Project

`hybrid` puts neural networks into mechanistic PK/PD models: work package 2 of
the M.Sc. thesis "Hybrid neural-network ODE models for PK/PD" (supervisor
Matthias König). The mechanistic model comes from `sbml2jax`, imported as a
package; this module adds data generation, networks and training. The plan of
the three variants (A covariate model, B effect model, C absorption UDE) and
the warm-up with plain networks is in `docs/hybrid/index.md` and
`docs/roadmap.md` at the repository root.
Python >= 3.11 (3.11 for Colab; CI and `.python-version` use 3.13), packaged
with hatchling (version in `src/hybrid/__init__.py`), environment pinned by
`uv.lock`. Runtime dependencies: `sbml2jax`, `jax`, `numpy`, `equinox`
(networks and models as one pytree), `optax` (optimizers).

## Repository

`hybrid` is a module of the monorepo `matthiaskoenig/neural-ode`; this
directory is a self-contained package (own `pyproject.toml`, `uv.lock`,
tests). `sbml2jax` is a path dependency on `../sbml2jax` (`[tool.uv.sources]`);
never import files of it directly. Run all commands below from `hybrid/`. CI:
`.github/workflows/hybrid.yml` at the repository root
(`working-directory: hybrid`, runs on changes under `hybrid/` or `sbml2jax/`);
pre-commit: `.pre-commit-config.yaml` at the root.

## Commands

```bash
uv sync --extra dev
uv run pre-commit install

uv run pytest          # unit tests (-n 4 with pytest-xdist)
tox r -e ruff          # lint and format check

uv run hybrid generate configs/warmup_absorption.toml   # simulate the panel of a case
uv run hybrid train configs/warmup_apixaban.toml        # generate if missing, train, evaluate
uv run hybrid evaluate <run directory>                  # metrics and figures from saved weights
uv run python examples/warmup.py configs/warmup_apixaban.toml ../docs/images/warmup-fits.png
```

## Structure

- `configs/`: one TOML file per case, read by `src/hybrid/config.py`.
  `warmup_absorption.toml` is the small test model (`docs/examples/absorption.xml`).
- `src/hybrid/data/`: `population.py` (sampling), `simulate.py` (batched panel,
  noise), `dataset.py` (`Panel`, split by patient), `io.py`.
- `src/hybrid/nn/`: `mlp.py` (with `zero_last`), `scaling.py` (`Scaler`, numpy
  constants which are saved but not trained), `panel.py` (`PanelNetwork`).
- `src/hybrid/training/`: `loss.py` (`gaussian_nll`, `ErrorModel`), `fit.py`
  (Adam then L-BFGS on any pytree, best validation loss), `checkpoint.py`.
- `src/hybrid/evaluation/`: `metrics.py`, `plots.py`.
- `src/hybrid/variants/`: the hybrid models A, B and C (empty so far).
- `src/hybrid/runs.py`: `HYBRID_RUNS`, dataset files by hash, run directories
  with `config.toml` and `run.json`. `warmup.py`: generate, train, evaluate.
  `cli.py`: the command `hybrid`.
- `notebooks/warmup.ipynb`: Colab entry point, committed without outputs.
- Tests write to a temporary `HYBRID_RUNS` (autouse fixture in `tests/conftest.py`).

## Principles

- No substance-specific code: model files, species and parameter ids, doses,
  units and covariates live in configuration. A second, small test model runs
  through the same code in the tests to catch hidden assumptions.
- Simulations are compiled with `jax.jit` and batched with `jax.vmap` over
  subjects and doses; output times are concrete (see
  `docs/sbml2jax/simulation.md`).
- Fixed random seeds; every result is regenerated by a script in the
  repository.
- Generated files (datasets, weights, logs, figures of runs) are never
  committed; they go below `HYBRID_RUNS`. Only figures of the documentation
  are committed, in `docs/images/`.
- Every hybrid model equals the mechanistic model at initialization (last
  network layer zero), checked by a test.
